# 🧮 Flutter Calculator App

A simple, elegant, and user-friendly **Flutter Calculator** that supports **Addition**, **Subtraction**, **Multiplication**, and **Division**.  
This project was created as a collaborative effort to explore Flutter UI design, logic building, and responsive layouts.

---

## 🚀 Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 📱 Responsive UI for Android & iOS  
- ⚡ Real-time calculation results  
- 🎨 Clean Material Design interface
