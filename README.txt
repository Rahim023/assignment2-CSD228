Glassy Calculator - Flutter
===========================

How to run:
1. Ensure Flutter SDK is installed and set up.
2. Unzip this folder into your workspace.
3. From project root run:
   flutter pub get
   flutter run

This project is configured to be responsive and should work on mobile and desktop platforms.

Features:
- Modern glassy UI with blur, gradients and shadow.
- Light & Dark theme toggle in app bar.
- + - × ÷ operations, decimal, backspace, clear, +/- toggle.
- Overflow handling (displays OVERFLOW for very large / invalid ops).
- Responsive layout for phones and desktops.
